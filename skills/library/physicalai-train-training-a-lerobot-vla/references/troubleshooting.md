# Troubleshooting LeRobot VLA runs through the engine

Failures seen while training and evaluating VLAs with `physicalai train lerobot`, and what fixes them.

| Symptom                                                                                                                                       | Cause                                                                                                                                          | Fix                                                                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `ImportError` / `ModuleNotFoundError` once training starts (e.g. `num2words` for SmolVLA)                                                     | The policy's LeRobot extra is not in the environment it ran in, usually because the type has no family environment and fell back to `default`. | Add a family environment (`physicalai-train-adding-a-lerobot-policy-env`). `inspect_vla.py` shows which environment a checkpoint will use.     |
| `ValueError: Feature mismatch between dataset/environment and policy config` listing missing `observation.images.camera1..N`                  | Pretrained checkpoint camera keys differ from the dataset's.                                                                                   | Pass `--rename_map` (suggested by `inspect_vla.py`). Missing slots are skipped when the dataset provides a subset of the checkpoint's cameras. |
| Warning `Could not read the policy type of <repo> ...; using the default LeRobot environment`                                                 | `--policy.path` is a Hub id and `config.json` could not be fetched (offline, gated, typo).                                                     | Log in (`hf auth login`) or download the checkpoint and pass its local directory; or add `--policy.type=<type>`.                               |
| `RuntimeError: level_zero backend failed with error: 20 (UR_RESULT_ERROR_DEVICE_LOST)` on Intel XPU                                           | Level Zero v2 copy-offload race hit by `torch.cat` in VLA attention.                                                                           | `export UR_L0_V2_FORCE_DISABLE_COPY_OFFLOAD=1` before training or evaluating.                                                                  |
| `Could not push packet to decoder: Invalid data found when processing input` in a DataLoader worker (Studio `physicalai fit`, not the engine) | Video decoders opened while computing quantile stats are inherited by forked workers.                                                          | Fixed by open-edge-platform/physical-ai-studio#1356; make sure the branch includes it.                                                         |
| `torchcodec ... cannot be loaded ... Falling back to 'pyav'`                                                                                  | No system FFmpeg libraries.                                                                                                                    | Harmless; decoding is slower. Install FFmpeg for torchcodec.                                                                                   |
| CUDA/XPU out of memory                                                                                                                        | Full fine-tune of a multi-billion-parameter VLA.                                                                                               | Check `inspect_vla.py`'s estimate; reduce `--batch_size`; use the policy's freezing / `train_expert_only` / dtype options or a larger GPU.     |
| `401` / `GatedRepoError` downloading weights or a tokenizer (PaliGemma, Gemma, some Qwen)                                                     | Gated model.                                                                                                                                   | Accept the licence on Hugging Face, then `hf auth login`.                                                                                      |
| Runtime actions wrong only on real cameras                                                                                                    | Raw uint8 frames not scaled to [0, 1].                                                                                                         | The LeRobot adapter converts uint8 → float32 / 255 and float64 state → float32; make sure the plugin includes that fix.                        |
| Loss near zero but the policy barely moves (Studio SmolVLA only)                                                                              | `use_random_input_noise=False` also zeroes the training noise.                                                                                 | Set `--model.init_args.use_random_input_noise=true` (the default since open-edge-platform/physical-ai-studio#1409).                            |
